# Prime-ajust-e-au-risque
Ce projet développe un modèle actuariel de tarification automobile pour estimer une prime adaptée au risque individuel. À partir des données des assurés, il utilise des modèles linéaires généralisés (Poisson pour la fréquence, Gamma pour la sévérité) afin d’ajuster les primes de manière équitable et techniquement robuste..
